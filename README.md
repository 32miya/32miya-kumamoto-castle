# 熊本城さんぽ

加藤清正が築いた熊本城（熊本県熊本市・特別史跡）を、スマホで歩いて巡れる3D散策アプリ。お城さんぽシリーズの一城です。

- **現代**: 令和3年（2021）に復旧した天守閣（中は博物館、6階は展望）、特別見学通路、復旧工事中の宇土櫓・本丸御殿、長塀、加藤神社、桜の馬場 城彩苑
- **江戸時代**: 武者返しの石垣、大天守・小天守、宇土櫓、飯田丸五階櫓、本丸御殿（昭君之間）と闇り通路、二の丸の重臣屋敷、古町の城下町
- **西南戦争（明治10年・1877）**: 天守炎上 → 城下の焼き払い → 薩摩軍の総攻撃 → 段山の攻防・兵糧攻め → 包囲が解かれる（籠城52日）を自動案内でたどる

公開: https://32miya.github.io/32miya-kumamoto-castle/

距離は実際より縮め、建物の配置と寸法は簡略化しています。記録の少ない部分（天守の内部・城下の家並み・兵の配置など）は、言い伝えと想像で補った再現です。共通素材は https://32miya.github.io/oshiro/common/ を使います。
